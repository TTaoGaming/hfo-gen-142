### Recurring library/knowledge failure reduction

Historical names included Book of Blood, heritage/reliquary, failure-antibody registry, Agent Skills/prose library, Golden/rehydration surfaces, and STRIFE/SPLENDOR libraries. Gen142 does **not** create another competing library ontology. The recurring failure classes are reduced into the canonical event schema above.

- `implemented_not_integrated`: a registry/library can exist while zero runtime consumers load or enforce it.
- `state_loss_and_stale_authority`: multiple recovery roots can each be internally green while disagreeing about current world state.
- `evidence_provenance_and_binding_drift`: a stochastic summary/projection can outlive evidence and become false authority.
- `architecture_sprawl_and_duplicate_ownership`: hints without atomic claim/lease permit undeclared duplicate reconstruction and manual reconciliation.

Promotion target is not a larger corpus. A remembered failure must eventually compile into a smallest forcing function, regression/admission check, recovery assay, or other measurable selection pressure; otherwise it remains `REFERENCE` heritage.
