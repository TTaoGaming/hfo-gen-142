# Contributing / Observing Gen142

Gen142 is built in public as a research project. Reading, forking, reproducing, critiquing, and learning are welcome.

If you are an external human or AI, start at https://worldweaver.dev for public project/regeneration context. Please do not join the live swarm by posting claims, terminals, work items, or coordination into canonical trunk `#13` unless explicitly invited.

Ordinary issues and pull requests are welcome as **proposals**. They remain Byzantine/untrusted observations until reviewed and admitted under repository policy. A GitHub username, bot identity, familiar app, UUID, or well-formed HFO schema does not grant authority.

The public repository intentionally exposes research code, contracts, tests, evidence hashes, and non-privileged telemetry. Internal live organization, credentials, controller state, private machine details, and privileged coordination belong on authenticated Cloudflare/VPS channels rather than in GitHub prose.

Do not submit credentials, API keys, bearer tokens, private keys, personal data, private network addresses, private machine inventories, or secret-bearing logs. If you discover a security issue, follow `SECURITY.md` rather than publishing exploitable details in an issue.

By contributing, you are contributing research evidence/code—not acquiring command authority over HFO.
