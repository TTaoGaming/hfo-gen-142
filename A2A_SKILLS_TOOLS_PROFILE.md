# Gen142 A2A / Skills / Tools Profile

Purpose: make JIT morphing portable without creating another HFO agent protocol.

## Ownership
- **A2A Agent Card**: standard discovery/self-description for an actually served durable agent endpoint. Do not advertise candidate/history as current capability.
- **Agent Skills**: progressive-disclosure procedures loaded only when relevant to the admitted Workload.
- **MCP / provider-native API / CLI**: tool and resource interfaces. No duplicate HFO tool bus.
- **GitHub evidence/admission**: immutable refs, currentness, measured capability, claim ceiling, effect ceiling, verifier/consumer receipts.
- **Cloudflare Agent/DO**: preferred durable actor identity/state owner for the gateway/runtime when admitted.
- **Thread/model/carrier**: disposable cognition supply.

## Hard boundaries
`AGENT_CARD_CLAIM != CAPABILITY_ADMISSION != EFFECT_AUTHORITY != EVALUATOR_TRUTH`

`SKILL_LOADED != TOOL_REACHABLE != TOOL_ADMITTED != EFFECT_AUTHORIZED`

A card may say what a served agent advertises; it does not prove the current carrier can execute the capability and never grants permission by itself.

## JIT morph target
Gateway sequence:

`UNCOMMITTED_CARRIER -> RECOVER -> WORKLOAD_SELECT -> CAPABILITY_MATCH -> ROLE_MORPH -> SKILL_LOAD -> TOOL_ADMISSION -> PDSA -> RESULT -> CONSUMER_ACK -> RELEASE`

Do not bind morphology to provider/model brand. Morph from current demand and measured capability.

## Public/runtime rule
Until a live Gen142 durable actor endpoint is admitted, keep any Agent Card as `CANDIDATE/HOLD`; do not fabricate URL, security, media, version, or served capabilities. When runtime exists, materialize the card from live facts and serve it at the standard discovery path.

## Initial skills
- `twinling-pdsa` — bounded gather/falsify/reduce cycle.
- future skills should be split only when activation traces show distinct reusable procedures and ablation value.

## Acceptance
A fresh carrier given only the Gen142 pickup sentence should recover state, morph to useful work, load only needed skills, use native tools, terminal with durable evidence, and require zero Tao context ferry after admission.
